# 📋 Clase 00: Presentación del curso

Herramientas y marcos de trabajo para todo el curso: instrumentación en general, Python y series de tiempo.

Versión navegable, con preguntas guía y progreso: <https://federicogmz.github.io/instrumentacion-geotecnica/lecturas.html#m0>

## 1. Python for Data Analysis, 3.ª ed.
McKinney, W. (2022). *O'Reilly (edición web abierta)*. — ⭐ Esencial

- **Cómo complementa la clase:** Sus capítulos sobre limpieza de datos, series de tiempo y agrupación respaldan las lecciones del laboratorio de Python: DataFrames, filtrado, remuestreo y ventanas móviles.
- **Pregunta guía:** ¿Cómo calcularías con pandas el acumulado móvil de lluvia de 7 días de una serie horaria?
- **Enlace:** https://wesmckinney.com/book/
- **Acceso:** Edición web abierta (no se redistribuye aquí)

## 2. Forecasting: Principles and Practice, 3.ª ed.
Hyndman, R. J.; Athanasopoulos, G. (2021). *OTexts (edición web abierta)*. — Complementaria

- **Cómo complementa la clase:** Formaliza los componentes de una serie (tendencia, estacionalidad, ruido) que usamos en el módulo 5 y enseña a medir si un pronóstico es bueno. Los ejemplos usan R, pero las ideas aplican igual en Python.
- **Pregunta guía:** ¿Qué parte de tu serie de sensor es tendencia, cuál es estacional y cuál ruido?
- **Enlace:** https://otexts.com/fpp3/
- **Acceso:** Edición web abierta (no se redistribuye aquí)

## 3. Geotechnical Instrumentation Reference Manual (FHWA-HI-98-034)
Dunnicliff, J. (1998). *FHWA / NHI*. — Complementaria

- **Cómo complementa la clase:** Visión de conjunto de los instrumentos y de la planeación de un programa de monitoreo; sirve de consulta durante el proyecto integrador. Es de 1998: la tecnología cambió, los principios no.
- **Pregunta guía:** ¿Qué pregunta concreta debe responder cada instrumento que propones en tu proyecto?
- **Enlace:** https://rosap.ntl.bts.gov/view/dot/75281/dot_75281_DS1.pdf
- **Acceso:** Publicación de la FHWA
